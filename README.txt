# Trading Bot Bybit

## Pliki:
- `bot.py` – główny plik bota
- `config.py` – konfiguracja API i ustawień
- `requirements.txt` – zależności do instalacji
- `README.txt` – ten plik

## Instrukcja:
1. Uzupełnij `config.py` swoimi danymi.
2. Zainstaluj wymagane pakiety: `pip install -r requirements.txt`
3. Uruchom bota: `python bot.py`
